1. Requirements Analysis

Literature review, interviews and observation; functional and non-functional requirements agreed and frozen.

2. System Design

Three-tier architecture, data structures, use case / class / ERD models and interface wireframes.

3. Implementation

Coding of the modules in HTML5, CSS3 and JavaScript; deployment to the Apache server under XAMPP.

4. Testing

Unit, integration, usability and performance testing against the frozen requirements.

5. Deployment & Maintenance

Installation on the demonstration machine, user documentation and corrective maintenance.
